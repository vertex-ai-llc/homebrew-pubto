# Pubto Homebrew Tap

Install Pubto Desktop and the matching `pubto` CLI on macOS:

```sh
brew tap vertex-ai-llc/pubto
brew trust --tap vertex-ai-llc/pubto
brew install --cask pubto
```

Homebrew asks for explicit trust because this is a third-party Tap maintained by
Pubto rather than an official Homebrew repository.

See [Pubto Downloads](https://pubto.dev/downloads) for available architectures,
direct downloads, checksums, and installation help.
